# Authoritative Calibration Artifacts — IMMUTABLE

This directory contains the ingested authoritative calibration dataset
(generated by `npm run calibration:ingest`). These files are evidence
records, not code.

## What is here

- `hkeaa-p1-*.json`, `hkeaa-p2-*.json`, `hkeaa-p3-*.json`, `hkeaa-p4-*.json`
  — official HKEAA exemplar provenance fixtures. The exemplar booklets
  publish **LEVEL labels only**; candidate scripts are handwritten scans
  with no text layer, and no numeric marks are published. Therefore
  `studentScript` and every `published*Score` are `null` and
  `criterionScoresOfficiallyPublished` is `false`.
- `hkeaa-leveldescriptors*.json` — verbatim official HKEAA level
  descriptor text per level (and per C/L/O dimension where the official
  headers exist).
- `hkeaa-ms-*.json` — the official Paper 2 marking scheme as a
  document-level reference.
- `manifest.json` — the list of ingested artifact ids.
- `quarantine.json` — source samples that could not be verified as
  authoritative fixtures (quarantined, never guessed).

## Immutability rules

1. **Never edit these files by hand.** They are regenerated from the
   official source material. Manual edits break provenance.
2. If the official source changes, re-run `npm run calibration:ingest`.
   Existing artifacts are never mutated: the ingestion either reports a
   content conflict (fail closed) or, with `--force-new-version`, writes a
   NEW versioned artifact next to the original.
3. Every fixture answers "where did this expected value come from?" via
   `provenance` (source document, year, paper, task/section reference,
   page range, SHA-256 source hash).

## Authority boundary

These fixtures are evaluation infrastructure ONLY. They are never read by
student-facing runtime code and never influence scores shown to students.
