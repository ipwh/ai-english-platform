## 一、HKDSE Paper 2 考試結構總覽

### 1.1 基本框架

| 項目 | Part A (Guided Writing) | Part B (Extended Writing) |
|------|------------------------|---------------------------|
| 佔分 | 10% (全科) | 15% (全科) |
| 比重比例 | 2 | 3 |
| 字數要求 | ~200 words | ~400 words |
| 建議時間 | 30-40 分鐘 | 80 分鐘 |
| 題目數量 | 1 題（必答） | 4 題選 1 題（2024改革後） |
| 滿分 | C:7 + L:7 + O:7 = 21 分 | C:7 + L:7 + O:7 = 21 分 |

### 1.2 2024 年重大改革（新制 vs 舊制）

| 項目 | 舊制 | 新制 (2024+) |
|------|------|-------------|
| Part B 題目數量 | 8 題 | **4 題** |
| 題目主題 | 對應 8 個 Electives | **不再掛鈎 Electives** |
| 主題相關性 | 學術性/特定專業性 | **更貼近考生日常生活** |
| 題目設計 | 與現實連結較弱 | 融入當代社會情境、熱點話題 |
| 題型特徵 | 較封閉 | **更開放性題目** |

## 二、出題模式深度分析

### 2.1 Part A 題型演變（重大發現！）

Part A 的出題模式在近兩年發生**根本性變化**，不再局限於傳統書信/電郵：

| 年份 | Part A 題型 | 文體 | 特點 |
|------|-----------|------|------|
| 2023 | 環保公司 Pop-up Store 申請表 | **申請表格** | 首次出現表格填寫！考核 Workplace 語境 |
| 2024 | 酒店投訴電郵 | Email（投訴信） | 基於廣告 vs 現實落差 |
| 2025 | 852 Teen Art Club 宣傳單張 | **Promotional Leaflet** | 全新題型！宣傳文案 |

**🔴 關鍵發現**：Part A 已不再是簡單的 "email/letter/notice"，而是出現了：
- 申請表格 (Application Form)
- 宣傳單張 (Promotional Leaflet)
- 公司簡介 + 產品介紹 + 活動推廣

這表示 HKEAA 正在**大幅擴展 Part A 的文本類型範圍**。

3. **職場語境 (Workplace) 持續出現**：2023 Part A + Q4/Q9, 2025 Q4
4. **科技/AI 主題**：2023 Q8（AI音樂）
5. **社會議題深度化**：退休觀念、生育率、寵物友善

## 三、題問用字分析

### 3.1 指令動詞 (Instruction Verbs) 分析

DSE Paper 2 常用指令動詞及其精確含義：

| 指令動詞 | 出現頻率 | 含義 | 注意事項 |
|---------|---------|------|---------|
| **Write** | 極高 | 撰寫 | 最通用 |
| **Explain** | 高 | 解釋原因 | 必須提供 reasons + elaboration |
| **Describe** | 高 | 描述 | 需要具體細節（Show, Don't Tell） |
| **Discuss** | 中高 | 討論利弊 | 必須包含雙方觀點 + 個人立場 |
| **Express your opinion/views** | 中高 | 表達意見 | 要有清晰立場 + 論據 |
| **Share your experiences** | 中 | 分享經歷 | 需第一人稱 + 具體事例 |
| **Elaborate on** | 低 | 闡述 | 需要深入拓展 |
| **Outline** | 低 | 概述 | 要點式呈現 |
| **Provide suggestions** | 中 | 提供建議 | 需具體可行方案 |

### 3.2 題目中的「隱藏要求」關鍵詞

DSE 題目常包含需要考生自行解讀的隱含要求：

- **"recently"** → 暗示需使用現在完成式 / 過去式
- **"you are a..."** → 設定角色身份，語氣必須配合（如 employee, school reporter, student）
- **"for a travel magazine"** → 暗示受眾 (audience) 為旅客
- **"based on the advertisement"** → 必須引用題目給予的材料
- **"include the following details"** → Part A 必須逐一涵蓋所有要點

### 3.3 題目中的情境設定用詞

| 情境類型 | 常見用詞 | 例子 |
|---------|---------|------|
| 學校 | school magazine, school reporter, fellow students, principal | 2023 Q3, 2025 Q? |
| 職場 | employee, employer, workplace, company, team | 2023 Part A, Q4, Q9; 2025 Q4 |
| 社會 | local newspaper, editor, survey, residents | 2023 Q7 |
| 個人 | friend, diary, blog, your experience | 2023 Q6, 2025 Q2, Q5 |
| 消費 | advertisement, hotel, customer, manager | 2024 Part A |

## 四、難度水平分析

### 4.1 CLO 評分框架下的難度分層

#### Content（內容）難度階梯

| Level | 分數 | 難度指標 |
|-------|------|---------|
| 5** | 7 | 內容完全貼題 + 觀點充分拓展 + 具體例子 + 高度創意 + 受眾意識 |
| 5 | 6 | 完全貼題 + 大部分觀點有拓展 + 創意 + 良好受眾意識 |
| 4 | 5 | 符合題目 + 多數觀點有拓展 + 一般受眾意識 |
| 3 | 4 | 大致符合 + 部分觀點有拓展 |
| 2 | 3 | 僅部分滿足 + 觀點未充分拓展 |

#### Language（語言）難度階梯

| Level | 分數 | 難度指標 |
|-------|------|---------|
| 5** | 7 | 句型極多變 + 純熟駕馭複雜句式 + 文法極精準 + 選詞細膩 |
| 5 | 6 | 廣泛句式 + 大致精準 + 多處進階用語 |
| 4 | 5 | 多種句式 + 嘗試複雜句 + 詞彙適度廣泛 |
| 3 | 4 | 簡單句大致良好 + 偶試複雜句 + 常用詞彙 |

#### Organization（組織）難度階梯

| Level | 分數 | 難度指標 |
|-------|------|---------|
| 5** | 7 | 結構極有效 + 層層展開 + Cohesion 極強 + 完全符合文體 |
| 5 | 6 | 組織有效 + 段落連貫 + cohesive ties 穩健 |
| 4 | 5 | 大致有效 + 大部分段落連貫 |
| 3 | 4 | 部分段落有主題 + 大致連貫 |

## 五、作文題材及深淺程度分析

### 5.1 歷年題材分類

#### 高頻題材（幾乎每年出現）
- **社會議題**：退休觀念、生育率、寵物友善、咖啡店文化
- **科技影響**：AI 創作、員工監控、社交媒體
- **青少年生活**：動漫文化、學校活動、朋友關係
- **個人成長**：生活改變、飲食習慣（vegan）

#### 中頻題材（隔年出現）
- **職場議題**：小組合作、員工監控、疫情經營
- **文化推廣**：太極拳、本地文化
- **環保**：環保產品、可持續生活

#### 新興題材（2024+）
- **社會趨勢**：FIRE 運動（財務自由提早退休）、YOLO
- **生活實驗**：Vegan 飲食、極簡生活
- **網絡現象**：Social Media 爆紅、網紅文化

### 5.2 題材深度層次

| 深度層次 | 特徵 | 例子 |
|---------|------|------|
| 表面層 | 只需描述/敘述，不需深入分析 | 動漫展報導、日記 |

| 深層 | 需要多角度分析 + 批判思維 + 社會視野 | 退休觀念差異、員工監控 |

## 七、具體改進建議（按優先級排序）

### 🔴 Priority 1 — 緊急（影響出題準確性）

#### 1. 新增 4 種缺失文體支援

```
新增文體：
├── proposal          → 計劃書（每年都可能是選項）
├── blog-entry        → 部落格文章（2025 Q5 已考）
├── promotional-leaflet → 宣傳單張（2025 Part A 已考）
├── feature-article   → 專題報導（2023 Q9 已考）
└── diary-entry       → 日記（2023 Q6 已考）
```

**實作建議**：
- 在 `DSE_TEXT_TYPE_GUIDE` 中新增上述文體
- 每種文體包含：requiredElements, structure, commonErrors, usefulOpeners, usefulClosers
- 在 `writing-generation.ts` 的 prompt 中加入對應的文體結構提示

#### 2. Part A 題型獨立處理

目前系統似乎將 Part A 和 Part B 混在一起處理。但 Part A 的題型已大幅擴展：

```
Part A 新題型：
├── email/letter（傳統）
├── application form（2023）    ← 全新
├── promotional leaflet（2025）  ← 全新
├── notice/announcement
├── instructions/guidelines
└── short report
```

**實作建議**：
- 新增 `generatePartAPrompt()` 函數，專門生成 Part A 題目
- Part A 需支援：表格填寫、宣傳文案、短報告等非傳統文體
- 字數限制 200 words，需在 prompt 中明確標示
- 必須有 "include the following details" 的要點式提示

#### 3. 更新題目生成 Prompt 以反映新制

目前的 prompt 可能仍基於舊制（8 Electives）。需要更新：

```
舊制 prompt 特徵（需修改）：
❌ 提及 8 個 Electives（Sports, Drama, Short Stories...）
❌ "Learning English Through..." 格式
❌ 題目與 Elective 掛鈎

新制 prompt 特徵（需加入）：
✅ 題目不掛鈎 Electives
✅ 以當代社會情境為背景
✅ 融入香港本地議題（生育率、寵物友善、咖啡店文化）
✅ 更開放的題目設計
✅ Part B 限 4 題
```

### 🟡 Priority 2 — 重要（提升評分準確性）

#### 4. CLO 評分框架細化

目前 CLO prompt 較為通用，建議加入：

**Content 評分細節**：
- 明確列出 DSE 7 分制每個分數的具體要求（已在 prompt 中，但可加強）
- 加入「受眾意識」(audience awareness) 的具體評分標準
- 加入「創意與想像力」(creativity and imagination) 的評分指導

**Language 評分細節**：
- 加入「語域」(register) 檢查：formal/informal 語氣是否配合文體
- 加入「句式多樣性」量化指標：簡單句/複合句/複雜句比例
- 加入文體特有語言要求（如 speech 需口語感、report 需被動語態）

**Organization 評分細節**：
- 加入文體特有結構檢查（如 letter 的地址/日期/稱呼/結尾配對）
- 加入段落連貫性 (cohesion) 的量化評估
- 加入 Cohesive devices 使用多樣性檢查

#### 5. 加入 Rule-based 格式驗證層

AI 評分之外，加入程式化格式檢查（無法被 AI 幻覺影響）：

```typescript
interface FormatValidation {
  // Letter
  hasSalutation: boolean;
  hasCorrectClosing: boolean; // Yours sincerely vs faithfully
  hasAddress: boolean;
  hasDate: boolean;
  usesContractions: boolean; // Formal letter 應為 false

  // Speech
  hasGreeting: boolean;
  hasThankYou: boolean;
  hasAudienceAddress: boolean; // "fellow students", "ladies and gentlemen"

  // Proposal
  hasTitle: boolean;
  hasSubHeadings: boolean;
  hasConclusion: boolean;

  // Article
  hasHeadline: boolean;
  hasByline: boolean;

  // Report
  hasTitle: boolean;
  hasSubHeadings: boolean;
  usesObjectiveTone: boolean; // 檢查第一人稱使用頻率
}
```

#### 9. PEEL 結構自動檢測

目前僅在 prompt 中提及 PEEL，建議加入自動檢測：

```
PEEL 檢測：
├── Point: 每段是否有清晰的主題句？
├── Explain: 是否有充分闡述？
├── Example: 是否有具體例子（數據/研究/個人經歷）？
└── Link: 是否有回連主題或過渡到下一段？
```

#### 10. Show, Don't Tell 專項訓練

```typescript
// 範例
const showDontTellExamples = {
  nervous: {
    tell: 'He was very nervous.',
    show: 'His palms were sweaty, his heart raced, and he couldn\'t stop tapping his foot.'
  },
  angry: {
    tell: 'She was angry.',
    show: 'Her jaw tightened and her voice dropped to a dangerous whisper.'
  }
```

#### 12. 連接詞/Cohesive Devices 多樣性分析

在評分中加入連接詞使用分析：

```
連接詞類別檢查：
├── 遞進: Furthermore, Moreover, In addition, Additionally
├── 對比: However, Nevertheless, In contrast, On the contrary
├── 因果: Therefore, Consequently, As a result, Thus
├── 舉例: For instance, To illustrate, A case in point is
├── 總結: In conclusion, To sum up, Ultimately
└── 讓步: Admittedly, Granted, Although, Even though
→ 分析學生是否只用 1-2 種連接詞，還是多樣化使用
```
